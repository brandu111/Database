Edge cases the coded engine must handle
• Month-end rollover — 31 Aug + 6 months has no 31 Feb; define the rule (last day of month vs first of next).
• Leap years — 29 Feb + N years lands on 28 Feb in non-leap years.
• Weekend / public-holiday roll-forward — a deadline on a non-business day rolls to the next business day, per each jurisdiction's IP-office calendar.
• Priority vs filing anchors — Convention Priority runs from the earliest priority date, not always the local filing date.
• Renewal anchor per jurisdiction — AU/NZ renew from filing; US/Madrid/others from registration. Confirm each.
• Rule versioning — record which rule version produced each date so changes can be recomputed and audited.
